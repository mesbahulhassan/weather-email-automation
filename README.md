# Weather Email Automation

A Python automation project that fetches weather data from the Open-Meteo API and sends a formatted weather report through Gmail SMTP.

## Features

- Fetches weather data using an API
- Processes and formats weather information
- Displays temperature, humidity, wind speed, and weather condition
- Sends the weather report automatically by email
- Uses environment variables to protect email credentials

## Technologies

- Python
- Requests
- Open-Meteo API
- Gmail SMTP
- python-dotenv
